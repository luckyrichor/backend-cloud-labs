# backend-cloud-labs

后端服务与云原生方向的实验集合。**刻意拆成多个各自独立、各自完整的小实验**，而不是一个什么都沾一点的大项目——后者的结果是五个岗位方向哪个都覆盖不了。

**状态：未开工**（2026-09-19）

## 对应岗位与实验拆分

| 岗位 | 实验 | 核心考点 |
|---|---|---|
| 06 字节 后端（导购）| 导购服务 + 缓存一致性 | 数据一致性、接口设计、降级 |
| 13 米哈游 游戏服务器 | 房间状态同步服务 | 长连接、状态同步、帧驱动 |
| 15 拼多多 C++ 研发（后端引擎）| 规则表达式求值引擎 | AST/字节码、性能、benchmark |
| 16 拼多多 弹性计算 | 简化版调度器（打分、装箱、抢占）| 资源调度算法 |
| 17 拼多多 云原生平台（CMDB）| 配置项模型 + 关系图 + 变更审计 | 数据建模、图查询、变更管理 |

岗位原文见 [workplan-docs](https://github.com/luckyrichor/workplan-docs)。

**重要边界**：这些实验共用基础组件（容器化、可观测、测试方法）能节省时间，但**共用组件不等于五个方向的专项能力都已覆盖**。每个实验的实际覆盖范围在其各自目录的 README 中说明，不做笼统声称。

## 技术栈

按实验而异：Go（06、13、16、17 方向）、C++（15 方向）。具体选型在各实验目录内说明。
