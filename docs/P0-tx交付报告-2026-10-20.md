## 失败、修复与边界

- E2 初版拆开配额破坏旧构造函数联动语义：恢复兼容，保留显式新配置。
- MySQL secret 读权限和临时服务器误报健康：修复权限，健康检查改正式 TCP 数据表查询，实际认证与 binlog 复核通过。
- 19090 已占用：保留其他进程，改用已探测空闲端口；运行镜像按实际 digest 固定。
- E3 HTTP 是调用现有 C++ AST 的受限演示，非吞吐优化；E4 仅补计时输出。E1 未加入 MySQL 商品源，E5 未加入 MySQL 事件存储，均属后续阶段。
