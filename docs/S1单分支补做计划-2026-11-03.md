## 范围

| 实验臂 | 读未命中回填 | 写路径 |
|---|---|---|
| `B-gate-only` | 版本门控 `PutIfNewer` | 提交源后 `DELETE`（A 的写路径） |
| `B-write-only` | 普通 `SET` | 提交源后普通 `SET` 回填（既有 B-off 逻辑） |

只跑这两个臂各 5 轮，repeat 1–5，臂顺序逐轮交替。**不重跑 A/B/B-off**；不增加自然负载、TX 直写、C/CV/D、其他延迟/速率/读写比或探针。失败与中断全部保留，不自动超过各 5 轮；质量不合格即停止，不改 `valid`、不更换 TX 客户端。

## 固定设计

- 读源回填故障延迟：50ms；读写比 95:5；400 请求/秒。
- catalog `catalog/b0e5aba50106/seed-20261023/8025233af339`；seed = 20261026 + repeat。
- warmup 10s、window 32s；Mac 四条独立业务 SSH + 独立控制流，10s 客户端等待，max-inflight 1536，每流 256 连接。
- TX 继续使用 `bcl_s1` 独立实验表、私有 `bcl-s1-redis`、原 loopback 端口和原 CPU/内存配置；不碰共享 `bcl.items`，不清共享 Redis，不重建数据。

## 分析与限制

- 复用全 key 审计、CSV 和 A.2 `calculate`；每轮报告陈旧数/成功读，五轮报告汇总比例、逐轮比例中位数及最小/最大。
- 源完整读计数、缓存 `sets/deletes/fills` 和 trace 用于证明实际路径；`B-gate-only` 要求写删除计数匹配写次数且没有普通 SET，`B-write-only` 要求写回填使用普通 SET 且没有门控回填。
- 旧参考 A/B/B-off 读取 `docs/measurements/2026-10-28-s1-v2/raw/race` 的 repeat 1–5，不重跑。旧参考源为 `a00e151`，新臂在之后的新冻结提交上运行，只能作跨批次描述性比较，不能当作同提交因果证明。
- 不预写收益；若观测不到差异或方向相反，照实报告。
